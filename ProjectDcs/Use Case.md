## 1. Use Cases

### UC-DOC-UI-001: Employee Views Documents

**Actor**: Employee

**Steps**:
1. Navigate to My Documents
2. View document list
3. Filter by type/status
4. Click document to view
5. Review content

---

### UC-DOC-UI-002: Employee Signs Document

**Actor**: Employee

**Steps**:
1. Open document awaiting signature
2. Review content
3. Click "Sign Document"
4. Draw signature on pad
5. Click "Submit Signature"
6. Confirmation displayed

---

### UC-DOC-UI-003: Employee Acknowledges Document

**Actor**: Employee

**Steps**:
1. Open signed document
2. Review content
3. Click "Acknowledge"
4. Confirm acknowledgment
5. Status updated

---

### UC-DOC-UI-004: HR Uploads Document

**Actor**: HR Admin

**Steps**:
1. Navigate to HR Documents
2. Click "Upload Document"
3. Select employee
4. Select document type
5. Upload file
6. Set expiry date
7. Submit
8. Success confirmation
